# Changelog

## 0.1.0

Первый релиз.

- Меню выбора аккаунта, сессии и проекта в стиле Claude Code, до пяти аккаунтов.
- Общие история, память, скиллы, агенты, команды, плагины, настройки и MCP-серверы между аккаунтами.
- Лимиты аккаунтов в меню и в строке состояния, `/switch-account` и `/switch-project` в чате.
- Подписи аккаунтов, избранные проекты, переименование и корзина для сессий, три темы.
- Значок в трее Windows с лимитами и уведомлением о сбросе лимита.
- Сборки для Windows (x64, ARM64, установщик), macOS (Apple Silicon, Intel) и Linux (x64, ARM64).
